# 🔥 FireGram

FireGram — это модифицированный клиент Telegram для Android, созданный с упором на расширение функционала и кастомизацию.

## 🚀 Особенности (Features)

На данный момент в клиенте реализованы следующие твики (доступны в отдельном меню "FireGram" в настройках):
- **Скрытый номер**: Прячет ваш номер телефона в профиле и настройках от посторонних глаз.
- **Бесконечный закреп**: Позволяет закреплять неограниченное количество чатов (обходит лимит в 5/10 чатов).
- **Отключение 18+ цензуры**: Снимает ограничения на просмотр чувствительного контента.
- **Компактные чаты**: Уменьшает высоту ячеек в списке диалогов для большей вместительности.
- **Секунды в сообщениях**: Отображает точное время сообщений вплоть до секунд.
- **Отключение двойного тапа**: Предотвращает случайные лайки/реакции при двойном нажатии на сообщение.
- **Подтверждение звонков (Voice/Video)**: Спрашивает подтверждение перед началом записи кружочка или голосового сообщения.

## 🛠 Сборка (Build)

Проект собирается в Android Studio. Убедитесь, что у вас прописаны ваши `API_ID` и `API_HASH` в `BuildVars.java`.

1. Клонируйте репозиторий.
2. Откройте проект в Android Studio (не через Import, а через Open).
3. Дождитесь синхронизации Gradle и соберите проект.
